## 12.5 Cost drivers and risks
- **Capillary integration effort:** depends on API maturity, sandbox availability and approval cycles. This is the biggest variable, and the main reason for the 15% contingency.
- **Native app release cycle:** the Suntec+ app team must ship the menu entry and the WebView kit (one store release).
- **Volume:** much higher than 300k members or 30k DAU calls for larger Supabase compute and read replicas.
- **Enterprise hosting mandate:** if Suntec+ requires its own AWS or Azure tenancy (see [03 §3.5](03-tech-stack.md#35-portability-an-exit-plan-if-it-requires-its-own-cloud)), add about 20–30 person-days of DevOps and higher running costs.
