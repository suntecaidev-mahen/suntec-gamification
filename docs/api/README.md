# Play & Win API — documents and Postman files

| File | What it is |
|---|---|
| `Suntec-Play-and-Win-API-Specification.docx` | Integration API specification: APIs Play & Win provides to Suntec+ / Capillary, APIs required from Capillary, status and error codes, Postman test plan |
| `Suntec-Play-and-Win.postman_collection.json` | Postman collection (29 requests with automatic checks) |
| `Suntec-Play-and-Win-UAT.postman_environment.json` | Postman environment for UAT — paste an API key into `api_key` (Admin → Administration → API clients) |

The machine-readable OpenAPI description is served at `/api/v1/openapi.json`.
